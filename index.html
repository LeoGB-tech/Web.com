Le relais

Un navigateur n’a pas le droit de lire le contenu d’un autre site : c’est ce qui provoquait l’erreur 405. Le relais est un mini-programme gratuit chez Cloudflare qui récupère les pages pour Ancre. Il ne stocke rien et reste privé grâce à ton code. À faire une seule fois.

Conseil : installe d’abord Ancre sur l’écran d’accueil et fais cette étape depuis l’appli installée (elle ne voit pas les réglages faits dans Safari).

  1. Copie le code du relais (il contient déjà ta clé privée).
  2. Ouvre Cloudflare et crée un compte gratuit (pas de carte bancaire).
    Ouvrir Cloudflare
  3. Dans Workers & Pages : Create → modèle Hello World → Deploy.
  4. Edit code → efface tout le code → colle → Deploy.
